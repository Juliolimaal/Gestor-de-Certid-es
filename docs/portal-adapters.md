# Adaptadores de portais

Cada portal terá um adaptador isolado com `id`, `displayName`, `sourceUrl`, `checkAvailability`, `start` e `resumeAfterUserAction`. O catálogo atual usa exclusivamente os seis endereços oficiais fornecidos no escopo.

A implementação real ainda não foi validada em navegador. O adaptador simulado percorre estados individuais para provar a orquestração sem utilizar CNPJs reais.
